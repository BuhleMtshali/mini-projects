## 🚀 Mini Projects Playground 🧪💻

### ***☕️ Java • 🐍 Python • 🎮 JavaScript — Same Logic, Different Languages***

Welcome to my Mini Projects Playground — a hands-on coding dojo where I sharpen my skills by rebuilding the same projects across multiple programming languages.

This repo is all about practice > perfection, logic > syntax, and doing the reps until problem-solving becomes second nature.

- If you’re here expecting polished production apps… wrong repo 😌

- If you’re here for growth, experiments, and “ohhhh THAT’S how it works” moments — welcome home.


## 🧠 Why This Repo Exists

- The goal is simple (but powerful):

    - Learn once. Rebuild everywhere.

- For every mini project, I aim to:

🔁 Recreate the same program in:

☕ Java

⚡ JavaScript

🧠 Compare how different languages solve the same problem

💪 Build muscle memory through repetition

- This repo is my coding gym. We lift logic here.
