## 🎲 Mini Number Guessing Game (JavaScript Edition) 🧩🔥

Welcome to my Mini Number Guessing Game — a CLI-based JavaScript game where luck, logic, and limited attempts collide 💥🎯

- The computer picks a random number between 1 and 20, and I get 5 attempts to guess it correctly.

- Guess right? 👉 Score goes UP 📈

- Run out of attempts? 👉 Pain. Growth. Character development 😭💀

And yes — you can keep playing because we don’t quit over here 😤🎮

## 🎯 Game Objective

- 🤖 Computer randomly selects a number (1–20)

- 🎮 Player guesses the number

- ⏳ Player gets 5 attempts

- 📊 Score increases for every correct guess

- 🔁 Player can replay the game as many times as they want

Simple idea. Big learning vibes 🧠✨

## ▶️ How to Run the Game

### 1️⃣ Install dependencies

- Make sure you’re in the project folder, then run:

```
npm install prompt-sync

```
### 2️⃣ Run the game 🎮

```
node index.js

```

- Boom 💥

- Game starts after a short dramatic pause ⏳😌

## 🕹️ How the Game Works

1. 🎲 A random number between 1–20 is generated

2. 🎯 You guess the number

3. 📉 If too high or too low → attempts decrease

4. 🎉 If correct:

    - Score increases 🆙

    - Round ends

5. 🔁 You choose whether to play again

6. 🏁 Game ends when you say “no”
